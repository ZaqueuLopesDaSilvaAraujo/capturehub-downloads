# CaptureHub

O CaptureHub é um aplicativo para Windows que grava a tela, captura imagens e organiza evidências de testes. Ele também pode registrar os passos executados e gerar uma apresentação PowerPoint editável ao final da gravação.

## Requisitos

- Windows 10 versão 2004 ou superior
- Aproximadamente 400 MB de espaço livre

## Como baixar e iniciar

1. Abra a página [Releases](https://github.com/ZaqueuLopesDaSilvaAraujo/capturehub-downloads/releases/latest).
2. Em **Assets**, baixe CaptureHub-0.8.0-Windows.zip.
3. Extraia todo o conteúdo do arquivo ZIP para uma pasta.
4. Abra a pasta extraída.
5. Dê dois cliques em Iniciar CaptureHub.cmd.
6. A barra do CaptureHub aparecerá na lateral direita da tela.

> Não execute o aplicativo diretamente dentro do ZIP. Extraia todos os arquivos antes de iniciar.

## Primeiro uso

Se o Windows exibir um aviso do SmartScreen:

1. Clique em **Mais informações**.
2. Confira se o arquivo aberto é o pacote do CaptureHub que você baixou.
3. Clique em **Executar assim mesmo**.

O aviso pode aparecer porque o pacote ainda não possui assinatura digital.

## Atalhos principais

| Atalho | Ação |
|---|---|
| Ctrl+Shift+1 | Capturar uma imagem |
| Ctrl+Shift+2 | Iniciar ou parar uma gravação |
| Ctrl+Shift+3 | Pausar ou retomar a gravação |
| Ctrl+Shift+M | Marcar um momento importante |
| Ctrl+Shift+A | Ligar ou desligar o microfone |
| Ctrl+Shift+H | Mostrar ou ocultar a barra |

## Criar uma apresentação

1. Abra as configurações do CaptureHub.
2. Ative **Registrar cada clique e montar a apresentação no fim**.
3. Inicie a gravação e execute o procedimento desejado.
4. Pare a gravação.
5. Revise os passos capturados no editor.
6. Clique em **Gerar apresentação**.

O arquivo .pptx será salvo junto da evidência gravada.
